async langgraph_agent_toolkit.core.memory.threads.list_threads(saver, *, user_id, agent_id, storage_key, limit=100, cursor=None)[source][source]

Read a bounded page of conversation identities from root checkpoints.

The cursor orders conversations by their first step 0 checkpoint. It does not order them by their latest activity. Other agents in the same user scope can require extra pages. Continue until next_cursor is None, including after an empty page. storage_key must bind public IDs to the authenticated owner and selected agent.
