Middleware that requests a direct answer near the model-call limit.

class langgraph_agent_toolkit.agents.components.middlewares.immediate_generation.ImmediateGenerationMiddleware(model_call_limit=None, instruction=None)[source][source]

Bases: AgentMiddleware

Request a direct answer on the last allowed model call.

The middleware removes tools and adds an instruction to the system message. It keeps tool results so the model can use collected data. The budget counts AI messages after the latest human message.
